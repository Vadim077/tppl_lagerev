# Отчет по выбору языков программирования и парадигм

## Задача 1. Обработка больших данных в реальном времени

* **Парадигма:** Императивная
* **Язык программирования:** C++

### Обоснование
1. **Большой поток данных:** Языки со сборщиком мусора вызовут паузы в работе, что приведет к потере кадров.
2. **Работа 24/7 и скорость:** В C++ можно один раз выделить буфер памяти и гонять данные по кругу без утечек и вылетов, а также C++ работает близко к железу и быстро выполняет математику на кадрах.
3. **Почему императивная:** Позволяет пошагово и точно контролировать, куда и как класть байты в памяти.

## Задача 2. Прототип ML-сервиса для прогноза погодных условий

* **Парадигма:** Объектно-ориентированная
* **Язык программирования:** Python

### Обоснование
1. **MVP и библиотеки:** На Python код пишется быстрее всего, для быстрого MVP это лучший выбор. Есть много готовых библиотек.
2. **Скорость:** Нам не сильно важна скорость, так как запуск происходит всего 1 раз в сутки.
3. **ООП:** Позволяет спрятать модели в одинаковые классы и легко менять алгоритмы.

## Задача 3. Интерактивный UI для торгового терминала

* **Парадигма:** Реактивная
* **Язык программирования:** TypeScript

### Обоснование
1. **< 16 мс:** Реактивный подход обновляет только ту цифру или график, где реально изменились данные, а не перерисовывает экран целиком.
2. **Связь между окнами:** Виджеты просто подписываются на потоки данных: кликнули в одном месте — данные синхронно обновились в остальных.
3. **Надежность TypeScript:** Защищает от багов и опечаток в данных, что критично в финансовом терминале.
4. **Тестируемость:** Логику реактивных данных легко проверить обычными быстрыми тестами отдельно от интерфейса.

## Задача 4. Прошивка для устройства регистрации температуры

* **Парадигма:** Процедурная
* **Язык программирования:** C

### Обоснование
1. **Мало памяти:** Программа на C весит мало и не тянет за собой ничего лишнего.
2. **Прямой доступ к железу:** На C проще всего работать с ножками и регистрами микроконтроллера напрямую по адресам.
3. **Экономия батарейки:** Чип мгновенно просыпается по прерыванию, за миллисекунды делает замер и тут же уходит в глубокий сон.
4. **Переносимость:** Компилятор C есть под любой микроконтроллер, код легко адаптировать под другую плату.
