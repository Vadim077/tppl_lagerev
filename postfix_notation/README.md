# Стековая машина (Постфиксная нотация)

Программа на языке Python для пошагового вычисления математических выражений, записанных в обратной польской (постфиксной) нотации.

## Поддерживаемые операции

- Базовые арифметические операторы: `+`, `-`, `*`, `/`
- Специальный оператор `~`:
  - Если оба операнда не равны `0`, вычисляет модуль их разницы `|x - y|` и кладет результат обратно в стек.
  - Если хотя бы один из операндов равен `0`, суммирует все значения в стеке (включая оба извлеченных операнда), возводит сумму в квадрат, очищает стек и кладет итоговый результат обратно в стек.

## Требования и установка

Для работы программы требуется **Python 3.8+**.
Для запуска тестов и проверки покрытия установите `pytest` и `pytest-cov`:

```bash
pip install pytest pytest-cov
```

## Запуск программы

Перейдите в директорию `postfix_notation` и передайте выражение через аргументы командной строки.

> **Важно:** Рекомендуется передавать выражение в кавычках, чтобы командная оболочка (терминал) не раскрывала специальные символы `~` (домашняя директория) и `*` (список файлов в папке).

### Примеры запуска

```bash
python main.py "3 0 4 ~ 2 ~"
python main.py "2 2 + 4 - 4 ~ 2 3 * +"
```

Вызов справки по использованию:

```bash
python main.py --help
```

### Пример вывода

При запуске `python main.py "3 0 4 ~ 2 ~"` программа выведет состояние стека на каждом шаге и итоговый результат:

```text
Шаг 1: токен '3' -> стек [3]
Шаг 2: токен '0' -> стек [3, 0]
Шаг 3: токен '4' -> стек [3, 0, 4]
Шаг 4: токен '~' -> стек [49]
Шаг 5: токен '2' -> стек [49, 2]
Шаг 6: токен '~' -> стек [47]
3 0 4 ~ 2 ~ = 47
```

## Запуск тестов и проверка покрытия

Для запуска тестов выполните:

```bash
pytest
```

Для запуска тестов с отчетом о покрытии кода:

```bash
pytest --cov=main --cov-report=term-missing
```
